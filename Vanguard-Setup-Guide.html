TEAM VANGUARD

First-time installation guide

Run setup.bat once. It checks for Python 3.10+ and Node.js 20+ and installs whichever runtime is missing.

  1. Keep the installers folder beside setup.bat. It contains the supplied Python and Node.js installers.
  2. If an installer file is missing, setup downloads that installer from the official Python or Node.js website. Internet access is needed only for missing installers and dashboard dependencies.
  3. Allow the Windows installer prompts to complete. If Windows requests administrator approval for Node.js MSI, approve it.
  4. Setup then downloads the dashboard, installs its dependencies, obtains the shared judging configuration, and starts Vanguard.
  5. For later use, run launch.bat. Do not rerun setup unless installation needs repair.
If setup stops: check logs\setup.log. Do not delete app\backend\.env or the app folder when repairing an existing installation.

Manual runtime fallback

If your organization's security policy blocks automatic installation, install the supplied Python and Node.js packages manually, then run setup.bat again.

Python: python.org/downloads
Node.js: nodejs.org/download
